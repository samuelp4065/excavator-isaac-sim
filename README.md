# Excavator Simulation in NVIDIA Isaac Sim

A four-joint excavator model, exported from CAD as a ROS 2 URDF package, imported into **NVIDIA Isaac Sim 5.1** and driven with a Python joint-position controller.

Click an STL file below to rotate and zoom it in GitHub's 3D viewer.

## Robot

| Joint | Type | Motion | Range |
|---|---|---|---|
| `swing_joint` | continuous (Z axis) | Rotates the cab on the base | 0 – 180° (0 – 3.14 rad) |
| `arm_joint` | continuous | Raises / lowers the arm | 0 – 46° (0 – 0.8 rad) |
| `pole_joint` | continuous | Swings the pole at the end of the arm | ±23° (±0.4 rad) |
| `bucket_joint` | continuous | Curls the bucket | ±29° (±0.5 rad) |

Links: `base_link` → `base_joint_1_1` (cab) → `arm_1_1` (arm) → `Pole_1` (pole) → `Bucket_1` (bucket)

All joints are `continuous` in the CAD export (no limits). The ranges above are the ones the sweep demo uses, set in its `JOINT_MOTION` dict; change them there if a part moves the wrong way or collides.

## Requirements

- Ubuntu 22.04
- NVIDIA RTX GPU
- [Isaac Sim 5.1](https://docs.isaacsim.omniverse.nvidia.com/) (standalone install, e.g. `~/isaacsim`)

## Workflow

### 1. Import the URDF into Isaac Sim

Needed once for the current model, and again whenever the URDF changes.

1. Launch Isaac Sim: `~/isaacsim/isaac-sim.sh`
2. **File → Import** → select `Excavator_Final_description/urdf/Excavator_Final.urdf`
3. Import options: **Fixed** base, joint drive type **Position**
4. The importer writes `urdf/Excavator_Final/Excavator_Final.usd`

Or do the same import headless, without opening the GUI (Isaac Sim must be closed):

```bash
~/isaacsim/python.sh scripts/import_urdf.py
```

It prints the joints it found in the new USD as a check.

### 2. Run the sweep demo

Close any open Isaac Sim window first, then from the repository root:

```bash
~/isaacsim/python.sh scripts/excavator_control.py
```

The script:

1. Creates a world with the default ground plane and lighting
2. Loads `Excavator_Final.usd` at `/World/Excavator` (exits with a message if it hasn't been imported yet)
3. Sets position-drive gains (kp = 1e4, kd = 1e3)
4. Sends smooth back-and-forth position targets to all four joints each physics step, within the ranges in `JOINT_MOTION`
5. Prints joint angles about once per second

```
DOF names: ['swing_joint', 'arm_joint', 'pole_joint', 'bucket_joint']
t=  1.0s  swing=...  arm=...  pole=...  bucket=...   (radians)
```

### Commanding a fixed pose

Set `lo` and `hi` to the same angle for each joint in `JOINT_MOTION`:

```python
JOINT_MOTION = {
    "swing_joint":  (np.deg2rad(90), np.deg2rad(90), 0.3),  # turn cab 90°
    "arm_joint":    (np.deg2rad(30), np.deg2rad(30), 0.5),  # raise arm 30°
    "pole_joint":   (0.0, 0.0, 0.7),
    "bucket_joint": (0.0, 0.0, 0.9),
}
```

### 3. Drive it with the keyboard

```bash
~/isaacsim/python.sh scripts/excavator_keyboard.py
```

Click inside the viewport so it has keyboard focus, then hold:

| Keys | Joint |
|---|---|
| Left / Right | swing (`swing_joint`) |
| Q / A | arm (`arm_joint`) |
| W / S | pole (`pole_joint`) |
| E / D | bucket (`bucket_joint`) |
| R | reset all joints to 0 |

Each joint moves at 0.5 rad/s (about 29°/s) while its key is held. Commands are limited to ±180°. Angles are printed in degrees while a joint moves.

### 4. Live editing (no restart)

```bash
~/isaacsim/python.sh scripts/run_live.py
```

`run_live.py` starts the sim once and loads the control logic from `scripts/live_controller.py`. Edit and save `live_controller.py` while the sim is running and the change applies within about half a second, with no restart. If the file has an error, the traceback is printed and the last working version keeps running.

In `live_controller.py`, set `MODE = "keyboard"` for the keyboard controls above or `MODE = "sweep"` for the automatic motion. Gains (`KP`, `KD`), key bindings, speed and sweep ranges are set in the same file. Only changes to `run_live.py` itself, which sets up the scene, need a restart.

### Regenerating the 3D preview

After changing the meshes or `Excavator_Final.urdf`, rebuild `docs/excavator.stl` and `docs/excavator.png`. This runs with the system Python (needs numpy, matplotlib and Pillow), not Isaac Sim:

```bash
python3 scripts/make_preview.py
```

## Troubleshooting

- **Isaac Sim crashes or freezes:** usually low memory. Isaac Sim recommends 32 GB RAM. Close other apps and don't run the GUI and the script at the same time.
- **Robot tips over or slides:** re-import with a **Fixed** base.
- **Arm oscillates:** lower the gains (`kps` in the standalone scripts, `KP` in `live_controller.py`), e.g. to `1e3`.
- **Keys do nothing:** click inside the viewport first so it has keyboard focus.
- **Don't run the script from Isaac Sim's Script Editor.** It creates its own `SimulationApp` and must be run with `python.sh`.
